# Cake photos

Make one folder per cake, named exactly like the cake's `id` in `src/data/menu.ts`,
and drop the photos in. They're shown in name order, and the first one is the cover.

    public/cakes/berry-me-in-love/1.jpg   ← cover (cards, home page)
    public/cakes/berry-me-in-love/2.jpg   ← shown on hover + in the gallery
    public/cakes/berry-me-in-love/3.jpg

Tips: portrait 4:5 (e.g. 1200 × 1500), JPG or WebP, under ~500 KB each.
Same backdrop and window light for every cake makes the menu look like a set.
No photos yet? The cake's illustration is used automatically.
